# Go parallels

pb's dependency model is Go's module system carried to protobuf, so
Go is the reference for every mechanism it shares: where pb does the
same, the row says so and why that is right here too; where pb
diverges, the row says why, and the divergence is a decision, never
an accident. A row states no contract — the spec it points at holds
the contract — and a row with no spec pointer is a gap to fill. This
note is a tracking artifact, extended as mechanisms land, every
identity a layer hands out walked once under one rule — a content
name names one content, a place name names a location, a
requirement's name lives in the graph; nothing kept-current cites it.

| Area | Go | pb | Same or diverges | Why | Spec |
| --- | --- | --- | --- | --- | --- |
| Module identity | `path@version`, the path a hostname-led import path | `path@version`, the path hostname-led | same | one identity for a module's bytes, spelled as its origin spells it | `module-resolution.md` REQ-resolve-path-syntax |
| Version selection | minimal version selection over the requirement graph | MVS over the requirement graph (`internal/mvs`) | same | reproducible, no solver, the highest of every requirement wins and nothing newer | `module-resolution.md` REQ-resolve-mvs |
| Workspace | `go.work` lists modules developed together; `go.work.sum` beside the members' own `go.sum` files | the workspace file lists modules under one root; one lockfile at the root, a member carrying one refused | same on the tree; diverges on the record | one build, one record of what it pinned: a member's own record would be a second source of truth for the same build | `workspace.md` REQ-work-lockfile |
| Replacement | `replace old => new v` in `go.mod`: the graph keeps `old`, the cache stores `new@v` under its own path, gopls addresses files there; a replacement may name one version of `old` (`replace old v1 => …`) or every version | `replace X: Y@v` makes Y@v stand for every version of X throughout the graph; addresses and the source store named by the replacement's pair, the pair whose bytes they are | same on the address; diverges on the version-specific form | a content name must name one content; the requirement's name belongs to the graph; one stand-in per path keeps the workspace file one line per replacement | `workspace.md` REQ-work-replace; `lsp.md` REQ-lsp-dependency-files |
| Where a replacement may be declared | `replace` in any `go.mod`, honored only in the main module's; the main module needs no workspace | `replace` in the workspace file alone; a module file carries none, and a replacement needs a workspace file | same in effect; diverges on the single module | a replacement is the build's decision, never a dependency's, and pb names the build a workspace | `workspace.md` REQ-work-replace |
| A replacement's declared path | the replacement's `go.mod` may declare the replaced path or its own; a forge fork left unedited replaces at once | the replacement's module file declares its own path; a fork still declaring the replaced path is refused | diverges | an archive makes one claim to the name it is fetched, verified and pinned under; pb's import paths are file paths, so a fork needs no declaration of the replaced path — the choice is filed for the user (replacement-declares-its-own-path) | `workspace.md` REQ-work-replace; `module-file.md` REQ-modfile-identity |
| A pair replaced and required in its own right | refused at load: one module used for two paths | two modules of the build, each providing the other's import paths, which the compile refuses as any duplicate provider, naming both | same outcome; diverges on where | the resolver needs no rule the compile has already; the error names `X@v => Y@w` and `Y@w` | `workspace.md` REQ-work-replace |
| Excluding and retracting versions | `exclude` in `go.mod`, `retract` by the module's author | neither | diverges | no need has arisen; a bad version is not selected by pinning what is required, and a retraction waits on a demonstrated need | `module-resolution.md` REQ-resolve-mvs |
| Directory replacement | `replace old => ./dir` | `replace X: ./dir` | same | a local checkout stands in for a pair, read from the tree | `workspace.md` REQ-work-replace-dir |
| Lockfile | `go.sum`: hashes per `module@version`, no record of use; `-mod=readonly` refuses to change `go.mod` | the lockfile pins (module, version) to the archive digest, the module-file hash and the provenance record, written on first use by a verb; the language server never writes a pin and resolves nothing unpinned | diverges | pb's lockfile is also the provenance record and the first-use consent; an editor must not grant consent | `module-lockfile.md` REQ-lock-first-use, REQ-lock-digest-enforcement; `lsp.md` REQ-lsp-unpinned |
| Integrity | `go.sum` + the checksum database, a transparency log queried at verify time | the archive digest pinned at first use, provenance by sigstore evidence (signed tags with their Rekor inclusion proof embedded, image signatures) verified offline against a pinned trusted root | diverges | nothing is queried at verify time: the evidence travels with the artifact and trust is per origin | `provenance.md` REQ-prov-offline, REQ-prov-signed-tag |
| Private and untrusted origins | `GOPRIVATE`, `GONOSUMDB`, `GONOSUMCHECK` exempt paths from the checksum database | the trust policy names, per origin prefix, the identity or keys that must have signed, and what an unsigned subject is recorded as | diverges | trust is stated as a policy per origin, not as an exemption list | `provenance.md` REQ-prov-trust-schema, REQ-prov-unsigned-recorded |
| Proxy | `GOPROXY`: `@v/list`, `@latest`, `.info`, `.mod`, `.zip` per version; a module with no `go.mod` served a synthesized one | a dumb proxy serving the same shapes and `.prov` beside them, every version-addressed artifact immutable once served; a module declaring no module file has no `.mod`, synthesized by the reader | same, plus provenance; diverges on synthesis | a module is fetched by path and version from a cache that needs no VCS; its evidence travels with it; a synthesized file is the reader's derivation, never a served artifact | `module-proxy.md` REQ-proxy-not-found; `module-resolution.md` REQ-resolve-synthesis |
| Major versions | `/vN` import paths from v2 on, `+incompatible` for a module declaring none | one path across majors; selection raising a module's major above a requirement's fails unless the root requires that major itself, the crossing then reported | diverges | an import path names a file, not a module, so a major needs no path of its own; the crossing is the graph's fact to report | `module-resolution.md` REQ-resolve-no-import-versioning, REQ-resolve-major-crossing |
| Module cache | `cache/download/<esc>/@v/<v>.{info,mod,zip,ziphash}` and an extracted `<esc>@<v>/` tree, every entry one content everywhere by the checksum database | `<esc>/@v/<v>.<digest>.{mod,zip,prov}` and `<v>.info`, no extracted tree (the language server's source store is its analog, keyed the same), the entry named by the digest that fixes it, two roots' pins of one pair two entries | same per-version layout; diverges on the kinds, the extracted tree and what makes an entry one content | no checksum database makes one pair one content across roots; a name of bytes carries what fixes them | `dep-verbs.md` REQ-dep-cache-layout, REQ-dep-cache-transparent |
| Repository mirror | `cache/vcs/<sha256(vcs+remote)>` | `vcs/<sha256(remote)>`, a fetch cache with no authority, its lock held for the holder's scope: a verb's run, a language server's judgement | same | a mirror is a place; every artifact built from it verifies | `module-proxy.md` REQ-proxy-direct-fetch |
| Vanity paths and finding the repository | `?go-get=1` and `go-import` for any version control system, known hosts, no probing | `?pb-get=1` and `pb-import` for git over HTTPS, a `.git` segment, else prefix probing by reference listing over the route the ssh setting gives | diverges | one VCS keeps the trust surface one; probing replaces a host table pb would have to carry | `module-resolution.md` REQ-resolve-vanity, REQ-resolve-vcs-suffix, REQ-resolve-probing |
| SSH routing | git's `insteadOf` rewrites the remote | the `ssh` setting routes a module's transport; its origin's identity, what provenance is held to and every record names, stays the HTTPS repository | same in effect | a route is not an identity | `module-resolution.md` REQ-resolve-ssh |
| Path escaping | upper-case letters escaped with `!` in cache and proxy paths | the same escaping | same | one case-insensitive-safe spelling for every filesystem and proxy | `module-proxy.md` |
| Standard files | a module path that clashes with the standard library is refused | the toolchain answers for the well-known imports; a copy shipped by any module is ignored in the toolchain's favor | diverges | one definition of `google/protobuf/*` per toolchain, and a module shipping a copy is common upstream, so it is tolerated rather than refused | `generation.md` REQ-gen-compile; `module-resolution.md` well-known imports |
| Tidy | `go mod tidy` adds missing and drops unused requirements, and prunes `go.sum` | `pb dep tidy`, pruning module, ruleset and plugin pins no declaration names | same | the module file follows the imports, the record follows the declarations | `dep-verbs.md` REQ-dep-tidy |
| Ruleset pins | none: a tool dependency sits in the one `go.sum` | a separate list of pins, one digest per pair across the lists | diverges | a ruleset is no member of the build list; the pair's bytes are one content whichever list names them | `module-lockfile.md` REQ-lock-ruleset-entry |
| Dependency source store | the extracted module cache, read-only, write-once, verified by `go.sum`, addressed by gopls as `file://` | copies under `<esc path>@<esc version>/`, read-only, filled from the bytes a judgement verified against the pins and replaced where they differ; `file://` into it where the client cannot fetch content | same layout and mode; diverges on the fill | the copies are a client's view of verified bytes, never a source | `lsp.md` REQ-lsp-dependency-files |
| Dependency file addresses | gopls hands out `file://` into the module cache | `pb-module://<path>@<version>/<file>` where the client offers `workspace/textDocumentContent`, the store's `file://` else | diverges | a client that fetches content needs no disk write; the address names the pair whose bytes the file is | `lsp.md` REQ-lsp-dependency-files |
| The toolchain's own files | `file://` under `GOROOT`, a place that changes on upgrade | `pb-module://well-known@<digest>/<file>`, the store's `well-known@<digest>/` | diverges | one address names one toolchain's bytes | `lsp.md` REQ-lsp-dependency-files |
| Plugin identity | none: no plugin store; the nearest is `go.sum`, a content hash per pair | an image's digest, pinned at first use, the tag resolved at the registry then and never again until an explicit update; evidence kept per digest whatever repository served it, judged under the rule governing the reference | diverges | a tag is its author's pointer, a digest the content; the pin turns the one into the other once | `plugin-execution.md` REQ-plugin-digest-pin; `dep-verbs.md` REQ-dep-update; `provenance.md` REQ-prov-plugin-evidence-kept |
| Local plugin identity | none | a host binary's content hash, pinned at first use per platform and held to at every run unless the trust policy disables local pinning; the bytes hashed and the bytes run one copy, the run's own | diverges | identity is the bytes, not the location | `plugin-execution.md` REQ-plugin-local-pin |
| Migration catalog | none | catalog names mapped to pb's registry references at migration, the pin the digest; a repository renamed or removed later leaves the pinned acquisition serving the pinned bytes or failing, never another image | diverges | a migration is a one-time rename, recorded nowhere but the files it wrote | `migrate.md` mapping table (term), REQ-migrate-gen |
