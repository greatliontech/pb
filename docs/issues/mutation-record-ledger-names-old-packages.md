# The mutation record's ledger names packages that no longer exist

Lands: gomutant's retarget-drops-a-record-then-refuses-the-rerun
resolved with its ledger arm (the compartment ledger's declaration
and file records following a package rename)

The package moves of the structure plan carried every record's
symbol identity to its new package, by gomutant's retarget or by the
textual rewrite that is its output for a package move. The
compartment ledger's declaration records and the candidates' file
positions kept the old names — `modfetch`, `httpspolicy`,
`protocomp`, `protoimport` and the rest — as the tool's own retarget
also leaves them. The ledger is the measured tree's, so every such
record is true of the tree it was measured on, and the judge reads
the records against the live tree by symbol; nothing consults the
dead names. What a reader of the document loses is the relation
between a historic record under one package name and a later
measurement of the same declaration under the new one.
